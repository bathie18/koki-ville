# koki-ville — prototype du site de la commune de Coki / Koki

Site statique (HTML/CSS/JS), sans outil de build. Hébergement prévu : GitHub Pages (dépôt `bathie18/koki-ville`).

- `config.js` : nom de la commune (Coki / Koki), devise, contact, pied de page, centre et emprise de la carte, lien de l'application cartographique. **C'est le seul fichier à modifier pour les textes courants.**
- `index.html` : contenu des sections (chiffres, projets, écoles, coopération).
- `assets/` : styles et script.

Publication : dépôt GitHub > Settings > Pages > branche `main`, dossier `/ (root)`.

À faire : confirmer l'orthographe officielle, remplacer l'emprise provisoire par la géométrie réelle (GeoJSON), renseigner le contact, ajouter logo et photos, relier la carte à l'application QWC une fois le projet Coki publié.
